# Code of conduct

## Our pledge

We want participating in this project to be a good use of your time, regardless
of experience level, background or identity.

## Standards

**Expected:** be direct about code and kind about people. Assume the other
person read the docs and still found it confusing — that is usually a docs bug.
Prefer a concrete example over an opinion. When you disagree, say what you would
do instead.

**Not acceptable:** personal attacks, harassment, dismissiveness toward
newcomers, publishing others' private information, or sustained disruption.

## Scope

Applies in issues, pull requests, discussions, and any space where someone is
representing the project.

## Enforcement

Report concerns via GitHub's private reporting or to the maintainers in
`CONTRIBUTING.md`. Reports are handled confidentially. Maintainers may edit or
remove contributions, and may temporarily or permanently ban accounts, for
behaviour they judge inappropriate.

Adapted from the [Contributor Covenant](https://www.contributor-covenant.org),
version 2.1.
